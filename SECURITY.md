# Security Policy

## Reporting a Vulnerability
Please report security vulnerabilities via GitHub Issues with the `security` label. Do not disclose publicly until a fix is available.

## What to Include
- Description of the vulnerability
- Steps to reproduce
- Impact assessment

## Supported Versions
| Version | Supported |
| ------- | --------- |
| latest  | ✅        |
| < latest | ❌       |

## Acknowledgments
We thank researchers who responsibly disclose vulnerabilities.
